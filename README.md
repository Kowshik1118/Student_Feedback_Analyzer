# Student Feedback Analyzer

A simple college project using Python, Flask, HTML, CSS, JavaScript and basic NLP techniques.

## Features

- Student feedback input
- Positive / Negative / Neutral sentiment
- Positive and negative word detection
- Keyword extraction
- Word count
- Feedback score
- Suggestions
- Feedback history
- Responsive interface

## How to Run

### 1. Open the folder in VS Code

### 2. Create virtual environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install Flask

```bash
pip install -r requirements.txt
```

### 4. Run

```bash
python app.py
```

### 5. Open browser

```text
http://127.0.0.1:5000
```

## Example

Enter:

"The teacher explains concepts clearly and the laboratory sessions are excellent."

The application analyzes the text and displays sentiment, score, keywords and suggestions.
